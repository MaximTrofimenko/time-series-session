# Сессионное задание: временные ряды

Анализ потребления домашних хозяйств на душу населения по регионам России
за 2000–2023 годы. В работе выделены три кластера регионов и сравнены прогнозы
Holt, ARIMA и наивной модели для Пермского края, Ярославской и Новосибирской областей.

## Файлы проекта

- [sz.ipynb](sz.ipynb) — ноутбук с кодом, сохранёнными таблицами, графиками и выводами по восьми этапам.
- [Отчёт в PDF](output/pdf/отчет.pdf) — письменный отчёт по тем же расчётам.
- `data/rsdocs_1491005410458_wide_appendix_2025.csv` — исходные данные Росстата.
- `requirements.txt` — зависимости для повторного запуска.

## Запуск

1. Откройте папку проекта в PyCharm и создайте виртуальное окружение Python.
2. Установите зависимости в это окружение:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Откройте `sz.ipynb`, выберите созданное окружение как ядро и выполните ячейки сверху вниз.
   Рабочая папка должна содержать ноутбук и каталог `data`.

## Как оценивается прогноз

Обучение: 2000–2017 годы, тест: 2018–2023. Модели выбираются на внутренней
валидации 2014–2017; тест не используется для настройки. Рассчитываются RMSE
и MAPE, а устойчивость проверяется скользящим окном.

Прогноз на 2024–2026 годы строится из конца 2023 года и не проверен более поздним
фактом. Значения приведены в текущих ценах, поэтому рост потребления включает инфляцию.
